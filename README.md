# Prof. Guilherme Nonino: E-books Power BI

Site oficial dos e-books **Power BI Básico** e **Power BI Avançado**, disponíveis na Hotmart.

Publicado com GitHub Pages a partir do arquivo `index.html` na branch `main`.

## Como editar

- Textos, preços e links ficam em `index.html`. Procure pelos trechos entre colchetes, como `[R$ PREÇO]`.
- Os botões "Comprar na Hotmart" usam links provisórios (`href="#basico"` e `href="#avancado"`). Troque pelos links de checkout da Hotmart.
- A cor de destaque é definida em `--accent`, no início do arquivo.
